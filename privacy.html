TicketPing Privacy Policy

Last updated: November 9, 2026

1. Introduction

TicketPing is a Discord bot that helps server moderation teams receive direct message notifications when new support ticket channels are created. This Privacy Policy explains what information the bot accesses, how it is used, where it is stored, and how users and server administrators can request its deletion.

2. Information We Access

To provide its functionality, TicketPing may access or process the following information:

  • Discord Server IDs.
  • Moderator role IDs selected by server administrators.
  • Server member IDs and relevant member information needed to identify members assigned to the configured moderator role.
  • Server names and ticket channel names, which are included in moderator notifications.
  • Basic information returned by Discord when processing notification delivery.

3. How We Use Information

TicketPing uses this information only to operate its ticket notification functionality.

When a new ticket channel is created, TicketPing checks the server's configured moderator role, identifies the members assigned to that role, and sends them a direct message containing the ticket channel name and server name.

TicketPing does not use this information for advertising, profiling, or selling personal information.

4. Data Storage and Retention

TicketPing stores server IDs and configured moderator role IDs in an encrypted configuration file in a private GitHub repository.

The configuration is encrypted using AES-256-GCM before it is transmitted to GitHub. The encryption key and GitHub access credentials are stored as environment variables in the bot's hosting environment and are not included in the public source-code repository.

Render is used to host and run the bot. The bot loads the encrypted configuration when it starts and decrypts it in memory for operation.

TicketPing does not intentionally store retrieved server member lists in its persistent configuration. Member information is retrieved when needed to identify moderators and deliver notifications.

Operational logs may contain limited technical information, such as notification delivery results, error details, and operational events. Logs are handled by the hosting provider according to its applicable retention and security practices.

Encrypted configuration may remain stored until it is updated or a deletion request is processed. Encrypted configuration may also exist in the private repository's version history.

5. Third-Party Services

TicketPing relies on the following services to operate:

  • Discord: Provides the platform, bot functionality, and API through which server and member information is accessed and moderator notifications are delivered.
  • Render: Hosts the bot and runs its application code.
  • GitHub: Stores the bot's encrypted configuration in a private repository.

These services may process information as necessary to provide their services and are subject to their respective privacy policies and terms.

6. Data Removal

Server administrators can remove TicketPing from their Discord server to stop the bot from accessing that server going forward.

Removing the bot does not automatically delete an existing saved server configuration.

Server administrators may request deletion of their server's stored configuration by emailing ticketping.support@gmail.com. Requests will be reviewed and the corresponding configuration will be removed where applicable.

Users may also contact us regarding privacy questions or data-related requests.

7. Security

TicketPing uses AES-256-GCM encryption to protect its stored configuration. Access to the private GitHub repository is restricted, and the encryption key and GitHub access credentials are kept separately from the encrypted configuration.

Reasonable measures are taken to protect information processed by the bot. However, no online service or method of transmission can guarantee absolute security.

8. Changes to This Policy

This Privacy Policy may be updated when TicketPing's functionality, storage arrangements, or data practices change. The latest version will be published at this policy URL.
